# Silent Sector

A 2D top-down sci-fi survival horror game for Windows. Board the dark research station Erebus, sneak past or fight mutants, manage your oxygen, and escape alive through four levels.

Made in Unity by Group 8.

## Download

**[Download Silent Sector for Windows](https://github.com/sHIzZYyyYYy/Silent-Sector/raw/main/Silent-Sector-PC.zip)** (zip, about 54 MB)

## How to run

1. Download the zip.
2. Right-click it and choose **Extract All**. The game won't run from inside the zip.
3. Open the `Silent Sector` folder and double-click `SilentSector.exe`.
4. If Windows shows "Windows protected your PC", it is because the game is unsigned. Choose **More info**, then **Run anyway**.

Requires 64-bit Windows.

## Controls

| Key | Action |
|---|---|
| W A S D / Arrows | Move |
| Hold Left Shift | Walk quietly |
| Mouse | Aim |
| Left click | Shoot |
| R | Reload |
| Right click | Throw a decoy |
| E | Interact, hide |
| Hold E | Plant explosive charges |
| M | Map |
| Esc | Pause |
